# Hotel Reservation System – CodeAlpha

A Java console application for managing hotel room availability and reservations.

## Features
- View available and booked rooms
- Room categories: Standard, Deluxe and Suite
- Book a room for selected nights
- Calculate total booking cost
- Cancel bookings
- Store booking details using Java objects and ArrayList

## Technologies
- Java
- ArrayList
- Object-Oriented Programming

## How to Run
```bash
javac Main.java
java Main
```
